About SummarAI

SummarAI is a Text and Speech Analysis project that shortens long text with Natural Language Processing.

NLP techniques

Text cleaning, sentence and word tokenization (NLTK), stop-word removal, Porter stemming, word-frequency analysis, TF-IDF (scikit-learn), sentence scoring combining TF-IDF, frequency and a small position bonus, and redundancy filtering with cosine similarity. Selected sentences keep their original order.

Technology stack

HTML, CSS and vanilla JavaScript on the front end. Python and Flask REST API on the back end. SQLite for storage. Chart.js for charts. Optional Hugging Face transformer for abstractive mode.

Limitations

Extractive summaries reuse original sentences, so they can read choppily or lose context. Pronouns may lose their referents. Quality varies by text type, and the tool is tuned for English. Abstractive summaries can introduce errors. Automated summaries should be reviewed before important academic or professional use.

Future enhancements

Multi-language support, PDF and URL input, ROUGE evaluation against reference summaries, user accounts, keyword highlighting in the original text, and speech-to-text input.
